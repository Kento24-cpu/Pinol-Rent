# Roadmap

## MVP (actual)
- [x] Autenticación (registro/login con email)
- [x] Roles de usuario (owner/renter)
- [x] Navegación con tabs
- [x] Tema visual azul
- [x] Tailwind CSS / NativeWind

## Fase 1 — Funcionalidades core
- [ ] CRUD de autos (owner publica, edita, elimina)
- [ ] Subir fotos a Supabase Storage
- [ ] Búsqueda y filtros de autos (marca, precio, ubicación)
- [ ] Vista detalle del auto
- [ ] Sistema de reservas con selección de fechas

## Fase 2 — Experiencia de usuario
- [ ] Perfil de usuario editable
- [ ] Historial de reservas (owner y renter)
- [ ] Notificaciones (confirmación, recordatorio)
- [ ] Calificaciones y reseñas
- [ ] Chat entre owner y renter

## Fase 3 — Producción
- [ ] Pagos (Stripe / Mercado Pago)
- [ ] Modo offline
- [ ] Push notifications
- [ ] EAS Build para Android APK / iOS IPA
- [ ] Deploy web a VPS con Nginx + PM2 + SSL
- [ ] Publicación en Google Play y App Store
